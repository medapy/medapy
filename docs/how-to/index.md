# How-to guides

Short, independent recipes for questions you already have, like "how do I select the files
swept downwards?" or "how do I symmetrize a measured sweep?". Each recipe stands on its own:
read the one you need and skip the rest.

The recipes assume you know the basics from the [Tutorials](../tutorials.md). For the full
signature of anything used here, follow the links to the [Reference](../reference/index.md).

- [Organize data files](files.md): build a collection from a folder, select files by
  parameters, contacts and sweeps, sort, rename and copy them.
- [Measurement sheets](sheets.md): read a file into a sheet, fix and convert units, name
  columns, combine sheets, calculate new columns, save.
- [Process data](processing.md): select ranges, interpolate, symmetrize, smooth and
  normalize.
- [Fit data](fitting.md): polynomial fits, linear Hall fits and multiband fits of
  resistivity.

The code is included from the scripts in
[`examples/how_to`](https://github.com/medapy/medapy/tree/master/examples/how_to), one per
page, which the test suite runs.
